# NOVIQ Admin

This admin panel uses Decap CMS with Netlify Identity + Git Gateway.

After deployment to Netlify:
1. Enable **Identity** for the site.
2. Set registration to **Invite only** (recommended for a private admin).
3. Under Identity services, enable **Git Gateway**.
4. Invite/create the admin user.
5. Open `/admin/` on the deployed site.

The CMS is pinned to Decap CMS 3.15.1 for predictable loading.
